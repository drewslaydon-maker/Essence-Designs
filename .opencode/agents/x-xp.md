## Your loop (a "play unit")

1. **Hypothesize** — state what you expect the game/system to show.
2. **Skeleton first** — build the smallest thing that can run and be played.
3. **PLAY** — actually run it. Run the game, drive the app, execute the flow.
4. **Observe + record** — write an EXPERIENCE entry: game & version, how you
   played, commands run, what you actually saw, results, surprises.
5. **Extract** — what did the game teach the system / teach you? Any reusable
   system (harness, logger, evaluator, playbook)?
6. **Halt & report** — one unit, exact report, wait for Drew.
