📜 Studio Reference & System Docs

🎮 Gameplay Modes

Mode A · Tower Campaign

Heaven's Arena ascent. The flagship single-player path.

  • Floors 1–50: Physical brawling & martial arts. Onboarding (Stamina, Guard, Strike, Counter).
  • Floors 50–100: Nen Awakening (Water Divination) & fundamentals (Ten, Zetsu, Ren).
  • Floors 100–199: Hatsu unlocking, advanced mechanics (Ko, Gyo, Ryu). Facing specialized Nen users.
  • Floor 200+: Registration & Point Matches against Floor Masters. Permanent consequences.

Mode B · Custom Hatsu Workshop

The Nen Lab — design, tune, and export.

  • Pick your Nen Category (Enhancer → Specialist).
  • Allocate base stats and affinity efficiency per the Nen Hexagon.
  • Craft Hatsu by combining Base Effect, Range/Targeting, and Oaths/Restrictions.
  • Export Nen Code or Build JSON to share with other players.

→ Try the live builder below in Hatsu Lab.

Mode C · Duel / VS Mode

Pass-and-play or room-code PvP.

  • Test custom Nen builds against preset Floor Masters or imported opponent builds.
  • Same engine, two pilots. Point Match scoring applies at Floor 200+.

WebRTC / WebSocket room codes land in V3.

🔮 The Nen Hexagon Efficiency Matrix

Each Nen type has 100% affinity in its own category and diminished efficiency in adjacent / distant categories. This is the table the engine loads into AFFINITY_MATRIX.

EnhancerTransmuterEmitter ConjurerManipulatorSpecialist
Enhancer 100%80%80% 60%60%0%
Transmuter 80%100%60% 80%40%0%
Emitter 80%60%100% 40%80%0%
Conjurer 60%80%40% 100%40%60%
Manipulator 60%40%80% 40%100%60%
Specialist 40%60%60% 80%80%100%

Read as: "An Enhancer attempting a Transmuter Hatsu lands at 80% efficiency." Numbers map directly to nen-engine.js → AFFINITY_MATRIX.

🏗️ System Architecture & State Machine

Two structures run the whole game: the per-fighter player state and the turn cycle that mutates it.

Player State

[Player State]
 ├─ Stats (Max HP, Max Aura, Atk, Def, Nen Efficiency)
 ├─ Aura Flow Stance (Ten / Zetsu / Ren)
 ├─ Active Aura Pool (Current / Max)
 ├─ Nen Category (Enhancer / Transmuter / …)
 └─ Hatsu List (Array of custom / unlocked abilities)

Combat Turn Cycle

1. Stance Selection — Maintain / Ten / Zetsu / Ren
↓
2. Action Choice — Strike / Guard / Ko Strike / Gyo Inspect / Hatsu / Item
↓
3. Speed & Priority Calculation
↓
4. Resolution & Aura Burn
↓
5. Point Scoring & Win Check (10 Points or KO)
