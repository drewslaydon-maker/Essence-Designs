## 🥁 CORE GAMEPLAY MECHANICS & ARCHITECTURE

1. **The Kitchen Tempo (BPM Engine):**
   - Every ticket/order arrives on a musical bar or beat.
   - Slicing, searing, plating, and washing dishes trigger rhythmic beat inputs (quantized timing window: Perfect, Good, Miss).

2. **The Chaos Multiplier & Heat Gauge:**
   - As orders build up, audio layers multiply (adds percussion, high hats, screaming sirens).
   - Performing actions on-beat keeps "The Kitchen Flow" steady and prevents burnout/tickets expiring.

3. **Audio-First Feedback Loop:**
   - Sound FX serve as primary visual/audio cues for game state (e.g., sizzle pitch rising = pan burning; bell ding = dish ready).

4. **Web-Native Delivery:**
   - Built on HTML5 Web Audio API & Canvas. Zero download, instant browser play on desktop or mobile touchscreens.
