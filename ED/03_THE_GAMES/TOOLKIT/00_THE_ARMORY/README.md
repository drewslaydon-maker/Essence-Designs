# 00_THE_ARMORY — Game Design Toolkit

**This is not a game.** It is the studio's shared game-design toolkit —
a workbench of reusable parts that LAG and future projects draw from.

Purpose:
- Shared UI, audio, and standard assets (the seeds of the Trinity-era UI
  kit live in the vault's fl0w hub).
- Reusable generator scripts, build helpers, and design-pattern templates.
- Cross-project conventions so a system proven in one game ports cleanly.

Rules:
- Anything generic enough for a second project belongs here.
- No project-specific code lives in the ARMORY — that lives with the game.
- Add a leaf to populate it; do not park empty folders as a substitute for
  intent (see OBSERVATORY sibling).
