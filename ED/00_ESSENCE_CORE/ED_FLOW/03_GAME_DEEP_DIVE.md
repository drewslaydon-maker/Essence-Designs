# GAME DEEP DIVE — Enshrined Future Task

> Charter enshrined during the **Goal 1.0 audit** (2026-09-17). This is a
> *future* task Drew wants canonized, not started today.

## 1. Purpose

A full, code-level inspection of every game in the studio, one at a time,
producing a rigorous technical + design dossier. Distinct from the Goal 1.0
audit (which cataloged *structure*); the Deep Dive inspects *substance*.

## 2. Scope

For each game, on a **go** from Drew:

- **Mechanics inventory** — what systems exist, what fires, what is dead.
- **Code health** — entrypoints, build pipeline, test coverage, known bugs,
  dead code, token-wall / crash risks.
- **Design audit** — what the game promises vs. what it delivers; gap list.
- **Recovery or retirement recommendation** — ACTIVE / repair path /
  PARKED / BROKEN / LEGACY, with rationale.

**Constraint (inherited from audit mode):** reading and reporting only.
No game code changes during the inspection. Fixes become separate approved
leaves.
