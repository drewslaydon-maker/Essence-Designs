## Data model (exact)

- `dock.json` stays import-pure, NEVER touched by this toss (no qty edits, no new items, no hand-edits).
- `CG/baked/trade.log.json` = the ONLY live ledger, append-only events + off-dock items:

```json
{
  "_doc": "DREW_SOURCED trade + off-dock ledger (CG-002-B). Live state entered via the CG console. Never regenerated by import/build; never inferred.",
  "schemaVersion": 1,
  "items": [
    {
      "id": "<uuid>",
      "item": "Sevagoth Prime",
      "partNames": ["Blueprint"],
      "created": "2026-10-07",
      "notes": null
    }
  ],
  "pickups": [
    { "id": "<uuid>", "date": "2026-10-07", "item": "Trumna Prime", "part": "Barrel" }
  ],
  "sales": [
    { "id": "<uuid>", "date": "2026-10-07", "item": "Trumna Prime", "part": "Barrel", "plat": 9, "buyerClass": "NOOB", "notes": null }
  ]
}
```

- Derived view (page-side only, never persisted, mirrors lastSync pattern):
  - Docked item part qty = base qty (dock.json, numeric part; null treats as 0) + `pickups.count(item,part)` − `sales.count(item,part)`; clamp ≥ 0; `have = qty >= 1`.
  - Off-dock item (in `items[]` with no dock base): parts exist with qty = pickups − sales on that item; renders in DEEP/GLANCE exactly like a dock item but flagged `OFF-DOCK` (chip, never silent).
  - `missing[]` for display shrinks as pickups land (a picked part leaves missing when qty ≥ 1).
  - **X / 11 today** = count of `sales` where `date` is today (local date, YYYY-MM-DD), rendered near the dock header when served over http.
